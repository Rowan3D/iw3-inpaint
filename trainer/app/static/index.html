iw3 inpaint trainer

Collect footage, prepare it, train a model, install it.

Where is nunif installed?

This is asked once and remembered. Pick the folder that contains nunif\ and iw3\ inside it — usually something like C:\nunif-windows\nunif. The trainer runs with that install's own Python, the one that has PyTorch in it.

Where files get stored

Leave these blank and everything is kept inside this GUI folder, so the whole thing stays portable. Set them once here and every later page uses them without asking again.

Appearance

1 · Collect footage

The model learns to fill in the gaps that appear at the edges of objects when a flat picture is pushed into 3D. To do that it needs a lot of ordinary scenes. Download some here, or point at footage you already have.

2 · Prepare the dataset

This turns your footage into what the model actually trains on. For every clip it estimates depth, warps the frame as if you were looking at it with one eye, works out which pixels have nothing behind them, and saves the picture and that hole mask as a pair. It is the slow step — it runs on your graphics card and can take hours on a big library. You can stop and restart it; finished clips are skipped.

Worth doing before a long run.

How clips are sampled

A clip is a short run of consecutive frames. These settings decide which frames get taken out of each video.

12 is what the model expects.

1 = every frame. 2 = every second frame.

0 = as many as the video allows.

0 = all of them.

Picture quality and geometry

0 = keep everything. Try 0.02 to drop blurry clips.

Depth model and speed

Depth edge refinement is off. Masks will follow a depth ramp of about 4.9 pixels instead of 1.3, and the only way to undo it is to build the dataset again. Leave it on unless you are testing.

3 · Train the model

This is the long part — days, not hours, for a full run. It is safe to stop and pick up again later, and you can watch it on the Live view tab while it works.

How long to train

Training is done in runs. Each run works through its epochs, then the next one starts again from the same weights with a fresh learning rate schedule. Results keep improving to about the third run.

5 · Install into iw3

This puts a finished model where iw3 can find it. Afterwards it appears in the Inpainting Model box in the iw3 window, from any of its launchers — you do not have to start iw3 from here.

Always included with the model: the mask handling it needs, and window reuse (each video frame runs once instead of twice). Every install refreshes all of it to this GUI's version.

What is installed now

What this changes on your computer

Three things, all reversible:

  • An entry in iw3\inpaint_models.yml, which is iw3's own list of inpainting models, pointing at a frozen copy of the weights in this GUI's models\installed folder. Your existing entries and comments are left alone, and a .backup copy is made the first time. Each name is its own entry, so several epochs can sit side by side for comparing.
  • A nt_inpaint folder inside nunif, holding the code that runs in iw3 — the same files the standalone installer puts there — and a config.json saying which pieces are on.
  • Two small files in this Python's packages folder (nt_iw3.pth and nt_iw3_register.py) that switch it on for every iw3 launcher. They cost nothing at startup and do not import PyTorch until iw3 itself is loaded. This GUI's older hook (ntrainer.pth) is removed, as it would conflict.

To undo it, run nt_inpaint\uninstall.bat in the nunif folder and remove the entries from the yml. NT_INPAINT_DISABLE=1 switches everything off without removing anything.
